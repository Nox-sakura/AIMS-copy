# 概念评分展示适配说明

以 AIMS 提交 3ca24e29a4bcbb5925aec3d13ddfaaac3a004116 为原版参照。缺失文件已补齐；当前仅局部修改概念评分区、训练场比例及模型显示名称。原病例、评级、备注、上传流程、胚胎对比、教学案例、教学反馈和一致率统计沿用原版。

## 概念评分区

四项卡片：卵裂球大小均一性、细胞质表现、透明带完整性、碎片化程度。前三项展示文字观察，碎片化展示百分比和比例条；无四项贡献占比、无额外来源徽章。保留原有蓝绿配色、字体与圆角。

九个内置病例配置独立预设，不从旧概念分数换算，也不根据传入等级自动补值。一级病例 ASS-2026-0021 显示均一、清晰均匀、透明带连续完整、碎片率 4%；4% 与原病例描述的 <5% 相容，也处于新版 Grade 1 的 <10% 参考区间。其他预设尽量与原病例文本一致。

仅在概念区底部以 10px 灰色文字标明形态数据、热力图和模型指标为演示预设，非本图像实测。报告预览的概念表采用同一内容及小字说明，其余部分沿用原版。

图像区恢复原始图和既有热力图，不与概念卡片联动，不显示“暂无区域标注”。既有热力图仍为固定展示资源，本次没有新增动态图像解释或测量模型。

## 训练及模型名称

训练场选择按钮的碎片率参考改为 <10%、10–25%、25–50%、>50%。原训练案例、答案、教学反馈和计分行为保留；未批量改写案例等级，也未添加停用计分规则。

模型显示名称采用 DenseNet169、LWMA-Net、多网络融合模型。内部兼容标识、请求与性能占位数值沿用原版；显示名调整不代表更换了后端实现，也不能据此声称复现文献性能。

## 数据与验证

morphologyEvidence 保留独立字段及来源、方法元信息，来源不逐卡展示。未提供新字段的外部记录仍不从旧分数或等级伪造测量。内置预设集中于 src/mock/assessments.js 和 src/mock/morphologyExamples.js。

npm test 验证旧分数隔离、零值与空值、来源、版本和显式预设；npm run build 验证构建。浏览器检查四项卡片、热力图、灰色小字、报告预览和原训练反馈。
